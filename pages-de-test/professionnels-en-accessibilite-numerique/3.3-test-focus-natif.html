Test 3.3 - Page dont tous les éléments ont un focus natif

Informations sur le test

Cette page est utilisée pour tester les bookmarklets d'accessibilité RGAA 4.1.2.

Nom du fichier : 3.3-test-focus-natif.html

Description du test : cette page ne contient que des éléments au focus natif, dont certains sont stylés hors focus (couleur, :hover, bordure), ce qui ne doit pas être confondu avec un style de focus, et d'autres stylés au focus sans que l'outline soit modifié (fond, ombre) : leur outline natif reste en place.

Résultat attendu : "Aucun élément avec un focus non natif détecté." Seule exception : le lien "Retour à la page précédente", stylé au focus par la feuille du site, est listé lorsqu'il est affiché (page ouverte depuis une autre page).
