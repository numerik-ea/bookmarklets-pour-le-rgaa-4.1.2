Test 9.3 - Structure des listes avec Shadow DOM

Informations sur le test

Cette page est utilisée pour tester les bookmarklets d'accessibilité RGAA 4.1.2.

Nom du fichier : 9.3-test-structure-listes-shadow-dom.html

Description du test : cette page contient des listes correctes et incorrectes dans le DOM principal, dans des Shadow DOM et dans des Shadow DOM imbriqués, afin de vérifier que le bookmarklet "9.3 - Vérifier la structure des listes" traverse bien les Shadow DOM.

Résultat attendu dans la console : 5 shadow roots analysés, une anomalie d'enfants directs non-<li> dans le Shadow root 1, deux anomalies (enfant direct + liste imbriquée) dans le Shadow root 2, une anomalie de <li> mal rattachés dans le Shadow root 3 et une anomalie d'enfants directs non-<li> dans le Shadow root 5 (Shadow DOM imbriqué de niveau 2), soit 5 anomalies au total.

Contenu du test

  • Premier élément de liste non ordonnée
  • Deuxième élément de liste non ordonnée

Shadow DOM 1 - Enfants directs qui ne sont pas des <li>

Shadow DOM 2 - Liste imbriquée directement dans une liste

Shadow DOM 3 - <li> hors de toute liste

Shadow DOM imbriqué - Liste incorrecte au niveau 2
