Test 10.2 & 10.3 - Désactiver CSS avec Shadow DOM et iframes

Informations sur le test

Cette page est utilisée pour tester les bookmarklets d'accessibilité RGAA 4.1.2.

Nom du fichier : 10.2_10.3-test-desactiver-css-shadow-dom-et-iframes.html

Description du test : chaque contexte de la page (document principal, Shadow DOM, Shadow DOM imbriqué, feuille adoptée, iframes de même origine, iframe dans un Shadow DOM, iframe imbriquée) contient un témoin rouge et encadré par ses propres styles, afin de vérifier que le bookmarklet "10.2 & 10.3 - Désactiver CSS TOGGLE" désactive les styles de tous ces contextes, puis les rétablit lorsqu'il est relancé.

Résultat attendu sans CSS : aucun témoin n'est plus rouge ni encadré, sauf dans le Shadow DOM fermé et dans l'iframe d'origine différente, que le bookmarklet ne peut pas atteindre.

Résultat attendu dans la console : 4 shadow roots traités (le Shadow DOM fermé n'est pas compté), 4 iframes traitées, 1 iframe non traitable (origine différente), et au total 9 feuilles de styles, 1 feuille adoptée et 3 attributs style désactivés. Au second lancement, les mêmes quantités sont réactivées.
