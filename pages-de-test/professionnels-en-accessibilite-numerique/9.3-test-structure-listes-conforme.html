Test 9.3 - Structure des listes conforme

Informations sur le test

Cette page est utilisée pour tester les bookmarklets d'accessibilité RGAA 4.1.2.

Nom du fichier : 9.3-test-structure-listes-conforme.html

Description du test : Toutes les listes de cette page ont une structure correcte (uniquement des <li> comme enfants directs, listes imbriquées placées dans un <li>, aucun <li> hors liste) afin de vérifier le cas sans anomalie du bookmarklet "9.3 - Vérifier la structure des listes".

Résultat attendu dans la console : un ✅ pour chaque liste et le message "Aucune anomalie de structure détectée dans les listes.".

Contenu du test

1. Liste non ordonnée simple

  • Premier élément de liste non ordonnée
  • Deuxième élément de liste non ordonnée
  • Troisième élément de liste non ordonnée

2. Liste ordonnée simple

  1. Première étape
  2. Deuxième étape
  3. Troisième étape

3. Liste imbriquée correctement dans un <li>

  • Élément de premier niveau
  • Élément de premier niveau contenant une sous-liste
    • Élément de deuxième niveau
    • Élément de deuxième niveau contenant une sous-liste
      1. Élément de troisième niveau
      2. Autre élément de troisième niveau
  • Autre élément de premier niveau

4. Liste dont les <li> contiennent d'autres balises

  • Un élément en gras
  • Un élément contenant un lien
  • Un élément contenant un <div>

5. Navigation avec une liste correcte

  • Lien de navigation 1
  • Lien de navigation 2
