Test 9.3 - Structure des listes avec iframes

Informations sur le test

Cette page est utilisée pour tester les bookmarklets d'accessibilité RGAA 4.1.2.

Nom du fichier : 9.3-test-structure-listes-iframe.html

Description du test : cette page contient des listes correctes et incorrectes dans le DOM principal et dans des iframes (simple, imbriquée dans une iframe, placée dans un Shadow DOM), ainsi qu'une iframe d'origine différente non analysable, afin de vérifier que le bookmarklet "9.3 - Vérifier la structure des listes" analyse bien le contenu des iframes de même origine.

Résultat attendu dans la console : 4 iframes analysées, 1 shadow root analysé, 1 iframe non analysable (origine différente) et les anomalies détectées dans chaque iframe (enfants directs non-<li>, liste imbriquée directement dans une liste, <li> hors liste).
