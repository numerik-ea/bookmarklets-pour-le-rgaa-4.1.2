Test 10.2 & 10.3 - Désactiver CSS

Informations sur le test

Cette page est utilisée pour tester les bookmarklets d'accessibilité RGAA 4.1.2.

Nom du fichier : 10.2_10.3-test-desactiver-css.html

Description du test : cette page transmet une partie de son information uniquement par les CSS (contenu généré, ordre visuel, contenu masqué), dans des feuilles de styles comme dans des attributs style, afin de vérifier que le bookmarklet "10.2 & 10.3 - Désactiver CSS TOGGLE" fait apparaître ces défauts, puis rétablit la page à l'identique lorsqu'il est relancé.

Résultat attendu sans CSS : les mentions « (champ obligatoire) » et « Promotion : » disparaissent (échec 10.2) ; les étapes et les colonnes s'affichent dans l'ordre du code, qui n'est pas l'ordre visuel, et le texte masqué réapparaît (échec 10.3) ; le témoin n'est plus ni rouge ni encadré.

Résultat attendu dans la console : 2 feuilles de styles et 4 attributs style désactivés dans le document principal. Au second lancement, les mêmes quantités sont réactivées.
