Test 9.3 - Structure des listes avec anomalies

Informations sur le test

Cette page est utilisée pour tester les bookmarklets d'accessibilité RGAA 4.1.2.

Nom du fichier : 9.3-test-structure-listes.html

Description du test : Cette page contient des listes dont la structure est incorrecte, pour les trois tests du critère 9.3 : listes non ordonnées et ordonnées (9.3.1 et 9.3.2, en HTML <ul>/<ol> et en ARIA role=list/role=listitem) et listes de description (9.3.3, <dl>/<dt>/<dd>).

Résultat attendu dans la console : les listes correctes sont signalées par un ✅, chaque anomalie est signalée par un ❌, les points à vérifier manuellement par un ⚠️, et le total des anomalies est affiché en fin d'audit. Cette page produit 14 anomalies sur 18 listes analysées, plus 1 liste dont la sémantique est remplacée par un role (à vérifier manuellement).
