Test 9.3 - Structure des listes avec anomalies

Informations sur le test

Cette page est utilisée pour tester les bookmarklets d'accessibilité RGAA 4.1.2.

Nom du fichier : 9.3-test-structure-listes.html

Description du test : Cette page contient des listes dont la structure est incorrecte (enfants directs autres que des <li>, listes imbriquées directement dans une liste, <li> hors liste) afin de tester le bookmarklet "9.3 - Vérifier la structure des listes".

Résultat attendu dans la console : les listes correctes sont signalées par un ✅, chaque anomalie est signalée par un ❌ et le total des anomalies est affiché en fin d'audit.
