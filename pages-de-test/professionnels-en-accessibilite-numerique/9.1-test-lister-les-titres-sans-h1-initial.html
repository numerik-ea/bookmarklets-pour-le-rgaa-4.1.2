Test 9.1 - Page dont le premier titre n'est pas un H1

Informations sur le test

Cette page est utilisée pour tester les bookmarklets d'accessibilité RGAA 4.1.2.

Nom du fichier : 9.1-test-lister-les-titres-sans-h1-initial.html

Description du test : le premier titre de cette page est un <h2>, et son unique <h1> n'arrive qu'en fin de page. Elle vérifie que l'arbre des titres signale le premier titre lorsqu'il n'est pas un H1, et qu'il ne signale pas à tort un retour à un niveau supérieur.

Au lancement, le bookmarklet vide la console, puis demande s'il faut afficher les avertissements de hiérarchie. Cette page vérifie les deux réponses. L'arbre attendu doit être le seul contenu de la console à l'issue du lancement.

Résultat attendu dans la console en répondant « Annuler », le comportement par défaut : un arbre de 5 titres, sans aucun avertissement.

   H2 Test 9.1 - Page dont le premier titre n'est pas un H1
   H2 Informations sur le test
   H2 Contenu du test
      H3 Premier sous-titre de la page
H1 Titre de niveau 1 placé en fin de page

Résultat attendu en répondant « OK » : le même arbre, avec un seul avertissement, sur le premier titre.

   H2 Test 9.1 - Page dont le premier titre n'est pas un H1 ⚠️ le premier titre de la page n’est pas un H1
   H2 Informations sur le test
   H2 Contenu du test
      H3 Premier sous-titre de la page
H1 Titre de niveau 1 placé en fin de page

Le dernier titre, un H1 placé après un H3, ne doit pas être signalé : revenir à un niveau supérieur ne rompt pas la hiérarchie, seul un niveau sauté vers le bas le fait.

Contenu du test

Premier sous-titre de la page

La page démarre sa hiérarchie à H2 : aucun H1 n'a encore été rencontré à ce stade du document.

Titre de niveau 1 placé en fin de page

Ce H1 arrive après un H3. Le passage de H3 à H1 est une remontée dans la hiérarchie, pas un saut de niveau.
