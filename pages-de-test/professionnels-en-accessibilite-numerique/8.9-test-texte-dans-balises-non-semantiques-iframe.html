Test 8.9 - Texte dans des balises non sémantiques avec iframes

Informations sur le test

Cette page est utilisée pour tester les bookmarklets d'accessibilité RGAA 4.1.2.

Nom du fichier : 8.9-test-texte-dans-balises-non-semantiques-iframe.html

Description du test : Cette page contient du texte dans des balises non sémantiques dans le DOM principal et dans des iframes (simple, imbriquée, dans un Shadow DOM, dans un parent caché) pour tester les critères d'accessibilité RGAA 4.1.2 concernant les contenus textuels dans des balises non sémantiques.

Contenu du test

Cette page contient :

  • Du texte dans une balise non sémantique dans le DOM principal (1)
  • Du texte dans des balises non sémantiques dans une iframe (2)
  • Du texte dans des balises non sémantiques dans une iframe imbriquée dans une iframe (1 + 1)
  • Du texte dans une balise non sémantique dans une iframe placée dans un Shadow DOM (1)
  • Du texte dans une balise non sémantique dans une iframe dont le parent est caché (1, signalé dans la console avec le parent caché)
  • Une iframe d'origine différente, qui ne peut pas être analysée
  • Du texte dans des balises sémantiques (ne doit pas être détecté)

Résultat attendu : 7 textes dans des balises non sémantiques (1 dans le document, 6 dans les iframes), 1 shadow root analysé, 5 iframes analysées, 1 iframe non analysable.
